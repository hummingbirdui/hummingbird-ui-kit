How it works

The kit uses class-based dark mode. Add this custom variant after importing Tailwind CSS and Hummingbird:

{{#code lang="css"}} @import 'tailwindcss'; @import '@hummingbirdui/hummingbird'; @custom-variant dark (&:where(.dark, .dark *), .dark); {{/code}}

Then set the class on <html> before the page renders. The saved preference wins, and the system preference is the fallback. The toggle logic lives in src/js/main.js.

Using a theme

The Default theme is included automatically. To use another one, import its CSS file after Hummingbird in src/css/style.css. Import only one theme at a time.

{{#code lang="css"}} @import 'tailwindcss'; @import '@hummingbirdui/hummingbird'; /* pick one */ @import '@hummingbirdui/hummingbird/src/themes/luxury.css'; /* @import '@hummingbirdui/hummingbird/src/themes/retro.css'; */ /* @import '@hummingbirdui/hummingbird/src/themes/arctic.css'; */ /* @import '@hummingbirdui/hummingbird/src/themes/nature.css'; */ /* @import '@hummingbirdui/hummingbird/src/themes/dracula.css'; */ /* @import '@hummingbirdui/hummingbird/src/themes/ember.css'; */ /* @import '@hummingbirdui/hummingbird/src/themes/midnight.css'; */ {{/code}}

Customizing tokens

Override any variable in an @theme block to match your brand:

{{#code lang="css"}} @theme { --color-primary: var(--color-emerald-600); --background-color-default: var(--color-stone-50); } {{/code}}
