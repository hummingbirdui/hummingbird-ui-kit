Quick start

Requires Node.js 20.19+. Install the dependencies, start the dev server and open http://localhost:3000.

{{#code lang="bash"}} npm install npm run dev {{/code}}

Run npm run build to export plain static HTML, CSS and JS to dist/. You can upload that folder to any static host.
